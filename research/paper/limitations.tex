\section{Limitations}
\label{sec:limitations}

We acknowledge the following limitations:
\begin{enumerate}
    \item \textbf{In-Memory Simulation Environment}: Evaluation is conducted in a thread-safe simulation engine; hardware testbeds with physical NVMe storage and kernel network stacks represent ongoing work.
    \item \textbf{Rapid Adaptation Throttling}: Extremely frequent policy re-evaluations ($\Delta t < 5\,\text{ms}$) can induce temporary election timer instability if threshold safety guards are disabled.
\end{enumerate}
