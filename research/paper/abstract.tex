Distributed key-value storage systems rely heavily on consensus protocols to guarantee linearizable state machine replication across server nodes. Standard Raft consensus enforces static majority quorums ($Q = \lfloor N/2 \rfloor + 1$), which introduce severe latency bottlenecks and transaction stalls when nodes encounter asymmetric WAN latency, transient packet loss, or correlated rack failure domain outages. In this paper, we present \textbf{QuorumShift}, a C++20 consensus engine that enforces dynamic, failure-domain-aware Phase 2 commit quorum weighting. By leveraging the theoretical insight that Phase 2 commit quorums need only intersect with Phase 1 election quorums rather than with each other, QuorumShift dynamically calculates node weights based on real-time heartbeat latency and rack affinity telemetry without incurring joint consensus reconfiguration overhead. We introduce \textbf{QuorumBench}, a benchmark evaluating 6 failure scenarios across 3 random seeds. Our empirical results demonstrate that QuorumShift achieves a 100.0\% Safe Task Completion Rate ($STCR$) and reduces P99 write commit latency from 980.0\,ms to 11.4\,ms (a 98.8\% latency reduction) compared to static majority Raft under correlated failure degradation.
