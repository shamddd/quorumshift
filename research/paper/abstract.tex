Distributed storage systems rely on state machine replication protocols like Raft to ensure fault tolerance. However, static replication factor placement and fixed majority quorums force operators into a rigid tradeoff: static low replication ($R=3$) suffers severe availability drops and tail latency spikes under correlated rack failures, while static high replication ($R=5$) incurs excessive network replication traffic during steady-state operations. In this paper, we present \textbf{AdaptiveReplica}, a failure-aware dynamic replication controller for distributed storage under correlated and dynamic faults. AdaptiveReplica dynamically adjusts replication factor ($R(t) \in [3, 7]$) and optimizes active replica placement across non-correlated failure domains using real-time node health, RTT latency, packet loss, and workload access skew signals, while formally preserving Raft election-write quorum safety ($Q_e \cap Q_w \neq \emptyset$). We evaluate AdaptiveReplica on a 16-scenario benchmark suite across 6 comparative baselines. Empirical results demonstrate that AdaptiveReplica achieves **99.97\% availability** and **13.50\,ms P99 write commit latency** under correlated rack degradation (a 93.7\% latency reduction over static $R=3$ Raft) while reducing network replication traffic by 31\% compared to static $R=5$ placement with zero linearizability violations.
