\section{Experimental Setup}
\label{sec:evaluation}

We evaluate AdaptiveReplica against 5 comparative baselines:
\begin{itemize}
    \item \textbf{B0}: Fixed $R=3$ Static Majority Raft.
    \item \textbf{B1}: Fixed $R=5$ Static Majority Raft.
    \item \textbf{B2}: Random Replica Placement ($R=3$).
    \item \textbf{B3}: Latency-Aware Placement ($R=3$).
    \item \textbf{B4}: Failure-Domain Static Placement ($R=3$).
    \item \textbf{B5}: **AdaptiveReplica (Proposed)**.
\end{itemize}

Experiments evaluate 16 failure scenarios across random seeds \texttt{\{42, 1337, 2026\}}.
